# exception — 에러 처리

에러가 났을 때 **사용자에게 보여줄 메시지로 바꿔주는** 곳입니다.

## 왜 필요한가요?

```
❌ NullPointerException 이 그대로 화면에 노출
✅ "이미 사용 중인 이메일입니다." 라는 안내 메시지로 변환
```

## 파일 예시

| 파일 | 역할 |
|---|---|
| `GlobalExceptionHandler.java` | 모든 에러를 한 곳에서 잡아 응답 형식으로 변환 |
| `CustomException.java` | 우리가 직접 정의한 에러 |
| `ErrorCode.java` | 에러 종류와 메시지를 모아둔 목록 |

## 상태 코드 참고

| 코드 | 언제 |
|---|---|
| 400 | 필수값 누락, 날짜 역전 |
| 401 | 로그인 필요 / 토큰 만료 |
| 403 | **남의 데이터**에 접근 시도 |
| 404 | 없는 일정 ID |
| 409 | 이메일 중복 |
