# jwt — 로그인 토큰 처리

로그인한 사용자를 **계속 기억하기 위한** 토큰 관련 코드입니다.

## 개념

```
① 로그인 성공  →  서버가 토큰(문자열) 발급
② 프론트가 저장  →  이후 요청마다 헤더에 담아 보냄
     Authorization: Bearer eyJhbGciOi...
③ 서버가 검증  →  "이 사람은 3번 회원이구나" 확인
```

HTTP는 요청 간에 상태를 기억하지 않기 때문에, 매번 "나는 누구다"를 증명해야 합니다.

## 파일 예시

| 파일 | 역할 |
|---|---|
| `JwtTokenProvider.java` | 토큰 생성·검증 |
| `JwtAuthenticationFilter.java` | 요청마다 토큰을 확인 |

## ⚠️ 주의

- **토큰 서명 키(secret)는 절대 코드에 직접 쓰지 마세요.** `application.properties`에서 읽습니다.
- 토큰 만료 시간·갱신 방식은 **팀 회의로 결정**해야 합니다 (요구사항 AUTH-02 비고).
