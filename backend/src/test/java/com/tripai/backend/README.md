# test — 테스트 코드

코드가 **의도대로 동작하는지 자동으로 확인**하는 코드를 둡니다.

## 왜 쓰나요?

기능을 고칠 때마다 손으로 전부 확인하기는 어렵습니다.
테스트를 만들어두면 명령 한 번으로 전체를 점검할 수 있습니다.

```bash
./gradlew test
```

## 파일명 규칙

```
{테스트대상}Test.java
```

예: `AuthServiceTest.java`, `PlanServiceTest.java`

## 예시

```java
@Test
void 이메일이_중복되면_예외가_발생한다() {
    // given - 준비
    // when  - 실행
    // then  - 검증
}
```

> 💡 메서드 이름을 **한글로** 써도 됩니다. 무엇을 검증하는지 명확해집니다.
> 시간이 부족하면 **핵심 로직(일정 생성, 날짜 검증, 권한 확인)** 위주로만 작성하세요.
