# 03. 개발 환경 설정

> 개발을 시작하기 전에 **각자 컴퓨터에 설치해야 하는 프로그램**들입니다.
> 담당 영역만 설치해도 되지만, 전체 흐름을 보려면 모두 설치하는 편이 좋습니다.

---

## 한눈에 보기

| 프로그램 | 버전 | 누가 필요? | 왜 필요? |
|---|---|---|---|
| **JDK (Java)** | 17 | 백엔드 | Spring Boot 실행 |
| **Gradle** | ❌ 설치 불필요 | - | `gradlew`가 자동 처리 |
| **Node.js** | 20 LTS | 프론트 | React 개발 서버·빌드 |
| **MySQL** 또는 **MariaDB** | 8.x / 10.x | 백엔드·DB | 데이터 저장 |
| **Git** | 최신 | 전원 | 코드 공유 |
| IDE (IntelliJ / VS Code) | 최신 | 전원 | 코드 편집 |

---

## 1. Git

### 설치

- **Windows**: https://git-scm.com/download/win → 설치 프로그램 실행 (기본 설정 그대로 Next)
- **macOS**: 터미널에 `git --version` 입력 → 없으면 설치 안내가 뜹니다
  또는 `brew install git`

### 확인

```bash
git --version
# git version 2.x.x 처럼 나오면 성공
```

---

## 2. JDK 17 (백엔드 담당)

Spring Boot 3.x는 **Java 17 이상**이 필요합니다.

### 설치

- **Temurin(추천, 무료)**: https://adoptium.net → Version **17 (LTS)** 선택 후 다운로드
- 또는 IntelliJ에서 프로젝트 생성 시 자동 설치도 가능

### 확인

```bash
java -version
# openjdk version "17.x.x" 처럼 나오면 성공
```

> ❗ `java version "1.8..."` 처럼 나오면 Java 8입니다. 17을 설치하고 환경변수를 다시 확인하세요.

## 3. Gradle — **설치하지 않아도 됩니다**

Spring Boot 프로젝트를 만들면 아래 파일이 함께 생성됩니다.

```
backend/
├── gradlew                          ← 맥·리눅스용 실행 파일
├── gradlew.bat                      ← 윈도우용 실행 파일
└── gradle/wrapper/
    ├── gradle-wrapper.jar
    └── gradle-wrapper.properties    ← 어떤 Gradle 버전을 쓸지 적혀 있음
```

이것을 **Gradle Wrapper**라고 합니다. 명령을 실행하면 필요한 Gradle을 자동으로 내려받아 씁니다.

```bash
cd backend
./gradlew build      # 맥/리눅스
gradlew.bat build    # 윈도우
```

> ✅ 덕분에 팀원마다 Gradle 버전이 달라서 생기는 문제가 사라집니다.
> 그래서 이 파일들은 **반드시 커밋**합니다. (`.gitignore`에 예외 처리되어 있음)

---

## 4. Node.js 20 LTS (프론트 담당)

React를 개발·빌드하려면 Node.js가 필요합니다.

### 설치

- https://nodejs.org → **LTS 버전** 다운로드 (20.x)
- npm은 Node.js에 함께 설치됩니다.

### 확인

```bash
node -v      # v20.x.x
npm -v       # 10.x.x
```

### 자주 쓰는 명령

```bash
cd frontend
npm install       # package.json에 적힌 라이브러리 설치 → node_modules/ 생성
npm run dev       # 개발 서버 실행 (http://localhost:5173)
npm run build     # 배포용 빌드 → dist/ 생성
```

> ⚠️ `node_modules/`는 용량이 크고 자동 생성되므로 **커밋하지 않습니다.**
> 새로 clone 받은 팀원은 `npm install` 한 번만 실행하면 됩니다.

## 5. 데이터베이스 (MySQL 또는 MariaDB)

둘은 거의 호환됩니다. **팀에서 하나로 통일**하세요.

### 설치

| | 다운로드 |
|---|---|
| MySQL | https://dev.mysql.com/downloads/installer/ |
| MariaDB | https://mariadb.org/download/ |

설치 중 **root 비밀번호**를 정하게 되는데, 꼭 기억해 두세요.

### 접속 확인

```bash
mysql -u root -p
# 비밀번호 입력 → mysql> 프롬프트가 나오면 성공
```

### 프로젝트용 DB 만들기

```sql
CREATE DATABASE tripai DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
SHOW DATABASES;
```

> 💡 `utf8mb4`로 만들어야 한글과 이모지가 깨지지 않습니다.

### GUI 도구 (선택, 편합니다)

- **DBeaver** (무료, 모든 DB 지원): https://dbeaver.io
- **MySQL Workbench** (MySQL 전용): https://dev.mysql.com/downloads/workbench/

## 6. IDE 선택

| IDE | 추천 대상 | 비고 |
|---|---|---|
| **IntelliJ IDEA** | 백엔드(Java) | Community(무료)로 충분. 학생은 Ultimate 무료 인증 가능 |

- ES7+ React snippets — React 자동완성
- GitLens — Git 기록 보기

## 7. 🔐 비밀 설정 파일 (중요)

DB 비밀번호와 API 키는 **절대 커밋하지 않습니다.**

### 백엔드

`backend/src/main/resources/application.properties` 파일을 **각자 직접 만들어** 사용합니다.
이 파일은 `.gitignore`에 등록되어 있어 커밋되지 않습니다.

> 필요한 설정 항목 목록은 [`backend/src/main/resources/README.md`](../backend/src/main/resources/README.md) 참고

### 프론트엔드

`frontend/.env` 파일을 직접 만들어 사용합니다. 역시 커밋되지 않습니다.

> 🙋 **팀원끼리 설정값은 어떻게 공유하나요?**
> 카톡·노션 등 **저장소 밖**에서 공유하세요. GitHub에 올리면 안 됩니다.
