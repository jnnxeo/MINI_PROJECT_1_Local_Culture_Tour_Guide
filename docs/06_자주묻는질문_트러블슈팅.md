# 06. 자주 묻는 질문 & 트러블슈팅

> 에러가 나면 **당황하지 말고** 여기부터 찾아보세요.
> 여기에 없으면 에러 메시지를 **그대로 복사해서** 팀에 공유하면 훨씬 빨리 해결됩니다.

## 🔧 Git / GitHub

### Q. `fatal: not a git repository` 라고 나와요

Git 저장소 폴더 **밖에서** 명령을 실행한 것입니다.

```bash
pwd          # 현재 위치 확인
ls -a        # .git 폴더가 보이는지 확인
cd MINI_PROJECT_1_Local_Culture_Tour_Guide   # 프로젝트 폴더로 이동
```

### Q. push할 때 로그인하라고 해요 / 비밀번호가 안 먹혀요

GitHub는 **비밀번호 대신 토큰**을 씁니다.

1. GitHub → 우측 상단 프로필 → **Settings**
2. 맨 아래 **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. **Generate new token** → `repo` 체크 → 생성
4. 나온 토큰을 **복사**(다시 못 봅니다) → push 할 때 비밀번호 칸에 붙여넣기

> 💡 GitHub Desktop을 쓰면 이 과정이 자동입니다.

### Q. `Updates were rejected because the remote contains work that you do not have`

내가 push하려는 브랜치에 **다른 사람이 먼저 올린 내용**이 있습니다.

```bash
git pull origin develop      # 먼저 받고
# 충돌 나면 해결 후 commit
git push origin 내브랜치      # 다시 push
```

> 🚫 `git push -f`(강제)로 밀어버리면 **남의 작업이 사라집니다.** 절대 쓰지 마세요.

### Q. 실수로 `node_modules`나 비밀번호 파일을 커밋했어요

```bash
git rm -r --cached node_modules        # 추적만 끊기 (파일은 남음)
git commit -m "chore: node_modules 추적 제외"
git push origin 내브랜치
```

> 🔐 **비밀번호·API 키였다면** 파일을 지워도 커밋 기록에는 남습니다.
> 반드시 **해당 키를 폐기하고 새로 발급**받은 뒤 팀에 알리세요.

### Q. 충돌(conflict)이 났어요

파일 안에 이런 표시가 생깁니다.

```
<<<<<<< HEAD
내 코드
=======
상대 코드
>>>>>>> develop
```

1. `<<<<<<<`, `=======`, `>>>>>>>` 줄을 **모두 삭제**
2. 최종적으로 남길 코드만 남김
3. `git add .` → `git commit`

> 어느 쪽을 남길지 모르겠으면 **그 코드를 쓴 팀원과 상의**하세요.

## ☕ 백엔드 (Java / Spring Boot / Gradle)

### Q. `./gradlew` 실행이 안 돼요 (Permission denied)

맥/리눅스에서 실행 권한이 없을 때입니다.

```bash
chmod +x gradlew
./gradlew build
```

### Q. 윈도우에서 `gradlew`가 안 먹혀요

윈도우는 `gradlew.bat`을 씁니다.

```bash
gradlew.bat build
```

### Q. `invalid source release: 17` / Java 버전 오류

JDK 17이 아닌 다른 버전이 잡혀 있습니다.

```bash
java -version      # 17인지 확인
```

IntelliJ 기준: `File → Project Structure → Project SDK`를 **17**로 변경

### Q. `Communications link failure` / DB 연결 실패

1. DB가 실행 중인지 확인 (MySQL/MariaDB 서비스 시작)
2. `application.properties`의 포트·비밀번호·DB 이름 확인
3. DB를 만들었는지 확인 → `CREATE DATABASE tripai;`

### Q. `Port 8080 was already in use`

이미 8080 포트를 다른 프로그램이 쓰고 있습니다.

```bash
# 맥/리눅스 — 8080 쓰는 프로세스 확인 후 종료
lsof -i :8080
kill -9 <PID>
```

또는 `application.properties`에서 포트를 바꿉니다: `server.port=8081`

### Q. 한글이 `???` 로 저장돼요

DB를 `utf8mb4`로 만들지 않은 경우입니다.

```sql
ALTER DATABASE tripai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

접속 URL에도 추가: `jdbc:mysql://localhost:3306/tripai?characterEncoding=UTF-8&serverTimezone=Asia/Seoul`

## ⚛️ 프론트엔드 (React / Node.js)

### Q. `npm install` 이 실패해요

```bash
# 캐시 정리 후 재시도
rm -rf node_modules package-lock.json     # 맥/리눅스
npm cache clean --force
npm install
```

> 윈도우는 탐색기에서 `node_modules` 폴더와 `package-lock.json` 파일을 직접 삭제하세요.

### Q. `command not found: npm`

Node.js가 설치되지 않았거나 터미널을 재시작하지 않은 경우입니다.
설치 후 **터미널을 완전히 껐다 켜세요.** → [`03_개발환경설정.md`](03_개발환경설정.md)

### Q. 백엔드 호출 시 **CORS** 에러가 나요

```
Access to fetch at 'http://localhost:8080/api/...' from origin
'http://localhost:5173' has been blocked by CORS policy
```

프론트(5173)와 백엔드(8080) **포트가 달라서** 브라우저가 막는 것입니다.
**백엔드에서** CORS 설정을 추가해야 합니다. (`global/config/` 에 설정 클래스 작성)

### Q. 포트 5173이 이미 사용 중이래요

이전에 켜둔 개발 서버가 살아 있습니다. 해당 터미널에서 `Ctrl + C`로 종료하거나,

```bash
lsof -i :5173
kill -9 <PID>
```

## 🗄️ 데이터베이스

### Q. `Access denied for user 'root'@'localhost'`

비밀번호가 틀렸습니다. 설치할 때 정한 root 비밀번호를 확인하세요.

### Q. 팀원과 DB 내용이 달라요

DB 데이터는 **GitHub로 공유되지 않습니다.** (각자 컴퓨터의 DB입니다)
[`database/schema/`](../database/schema/)의 SQL을 각자 실행해서 **구조만** 맞춥니다.

## 📨 도움 요청할 때 이렇게 알려주세요

에러를 공유할 때 아래 4가지를 함께 적으면 훨씬 빨리 해결됩니다.

1. **무엇을 하려다가** (예: `npm run dev` 실행)
2. **어떤 에러가 났는지** — 메시지 **전체 복사** (스크린샷보다 텍스트가 좋습니다)
3. **내 환경** (윈도우/맥, Java·Node 버전)
4. **이미 시도해 본 것**
