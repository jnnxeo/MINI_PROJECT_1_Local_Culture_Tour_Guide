# 메인페이지 월별 행사 조회 (API-EVENT-003)

## 요청

`GET /api/events/months/{month}?category={category}&page={page}&size={size}`

- 로그인 후 발급받은 Access Token이 필요하다.
- `month`: 필수, `YYYY-MM` 형식.
- `category`: 생략하면 전체 행사. 현재 지원 값은 `전시`, `공연`, `전통문화`, `축제`, `교육·체험`, `기타`.
- `page`: 생략하면 0. 0부터 시작한다.
- `size`: 생략하면 10. 허용 범위는 1~100. 메인페이지의 각 목록은 10을 사용한다.
- 조건이 잘못되면 400, 인증 정보가 없으면 401을 반환한다.

## 조회 및 응답

행사의 시작일이 선택 월의 마지막 날 이하이고 종료일이 선택 월의 첫날 이상이면 포함한다. 경계일도 포함하며 `display_yn=true`인 행사만 조회한다. 시작일 오름차순, 같은 시작일이면 행사 ID 오름차순으로 정렬한다. `totalCount`에는 해당 조건의 전체 건수가 들어가며 `items`에만 페이지 크기를 적용한다.

```json
{
  "success": true,
  "data": {
    "month": "2026-09",
    "items": [
      {
        "eventId": "12345",
        "title": "행사명",
        "category": "전시",
        "district": "종로구",
        "startDate": "2026-08-25",
        "endDate": "2026-09-05",
        "freeYn": null,
        "fee": null,
        "imageUrl": null
      }
    ],
    "totalCount": 1
  },
  "message": null
}
```

`freeYn`과 `fee`는 DB의 값을 그대로 반환한다. 요금 정보가 없는 경우 `null`을 화면에서 `요금 정보 없음`으로 표시한다. 결과가 없어도 정상 응답이며 `items=[]`, `totalCount=0`이다.

메인페이지는 같은 `month`로 전체, `category=전시`, `category=공연`을 각각 조회하면 된다. 목록의 더 보기는 해당 조건과 `page`를 검색 결과 화면에 전달한다. 현재 프론트의 `getHomeEventPreviews()`는 `/api/events`를 호출하므로 이 월별 조회 경로와의 연결은 별도 연동 단계에서 진행한다.

## 서울시 문화행사 분류 대응

서울시 문화행사 정보 API의 `CODENAME`을 `event.event_type`에 원문 그대로 저장하는 방식을 기준으로 한다. 다음 대응은 API 응답 1,000건에서 실제 확인한 분류값을 바탕으로 만든다. 표본에 없는 새로운 분류값은 전체 조회에 포함하고 응답의 `category`에 원문을 반환한다. 분류가 추가되면 이 표와 `EventCategory`를 함께 갱신한다.

| 화면 분야 | 서울시 `CODENAME` |
|---|---|
| 전시 | 전시/미술 |
| 공연 | 국악, 독주/독창회, 무용, 뮤지컬/오페라, 연극, 콘서트, 클래식 |
| 전통문화 | 축제-전통/역사 |
| 축제 | 축제-관광/체육, 축제-기타, 축제-문화/예술, 축제-시민화합, 축제-자연/경관 |
| 교육·체험 | 교육/체험 |
| 기타 | 영화, 기타 |

화면 분야 이름이 이미 `event_type`에 저장된 경우에도 같은 분야로 조회한다. 수집·적재 기능은 이 API 범위에 포함하지 않으며 데이터가 적재되지 않았다면 빈 목록이 반환된다. API 키는 추후 수집 기능에 사용할 환경변수 `SEOUL_CULTURE_API_KEY`로만 관리한다.
