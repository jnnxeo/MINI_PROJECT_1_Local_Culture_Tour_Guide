# 문화행사 검색 결과 조회 (API-EVENT-001)

## 범위

`GET /api/events`는 로그인한 사용자의 검색 결과 화면(`/events`)에 행사 목록을 제공한다. 메인페이지의 월별 카드 조회는 기존 `GET /api/events/months/{month}`를 사용한다. 행사 수집·적재, 행사 상세, 관심행사 등록·해제는 이 API의 범위에 포함하지 않는다.

## 요청

```text
GET /api/events?keyword=종로구&page=0&size=10
GET /api/events?month=2026-09&category=전시&category=공연&district=종로구&freeYn=true&sort=startDateAsc&page=0&size=10
```

| 파라미터 | 규칙 |
|---|---|
| `keyword` | 선택. 앞뒤 공백을 제거하고 행사명·장소·자치구/주소·분야 중 한 필드에 검색어가 포함된 행사를 조회한다. 영문 대소문자는 구분하지 않는다. 검색어의 단어 분해나 자동완성은 이 API에서 제공하지 않는다. |
| `month` | 선택. `YYYY-MM` 형식. 생략하면 월 조건을 적용하지 않는다. |
| `category` | 선택. `category=전시&category=공연`처럼 반복할 수 있다. 선택한 분야 사이에는 OR를 적용하며, 생략하면 전체 분야를 조회한다. 화면 분야와 서울시 원본 분류의 대응은 `EventCategory`를 사용한다. |
| `district` | 선택. 생략하면 전체 서울 지역을 조회한다. |
| `freeYn` | 무료만 보기에서 `true`를 보낸다. 선택하지 않으면 파라미터를 생략하며 무료·유료·요금 정보 없음 행사를 모두 포함한다. `false`가 전달돼도 필터를 적용하지 않는다. |
| `sort` | 선택. 기본값 `startDateAsc`. 아래 정렬표의 값만 허용한다. |
| `page` | 선택. 기본값 0, 0부터 시작한다. |
| `size` | 선택. 기본값 10, 허용 범위 1~100. |

메인페이지의 키워드 검색은 `keyword`만 보내므로 저장된 표시 대상 행사 전체에서 키워드에 맞는 행사를 찾는다. 메인페이지의 조건 검색은 기본값인 현재 월을 `month`로 보내며, 분야·지역·무료 필터의 기본값은 각 파라미터를 생략한다. 필터 화면의 `초기화`는 편집 중인 선택값만 기본값으로 돌린다. 이후 `검색`을 누르면 새 조건으로 조회하며 결과 페이지는 0부터 시작한다.

서로 다른 종류의 조건은 AND로 결합한다. 예를 들어 `month=2026-09&category=전시&category=공연&freeYn=true`는 9월에 걸치는 무료 행사 중 전시 또는 공연을 조회한다. 같은 행사는 목록과 전체 건수에서 한 번만 센다.

## 검색·정렬

`display_yn=true`인 행사만 조회한다. `month`가 있으면 `event_start_date <= 선택 월의 마지막 날`이고 `event_end_date >= 선택 월의 첫날`인 행사를 포함한다. 경계일도 포함한다.

키워드는 행사명(`event_name`), 장소(`event_place`), 자치구·주소(`district_name`, `addr`), 행사 분야(`event_type` 원본 값 또는 화면 분야명) 중 어느 하나에 포함되면 일치한다. 예를 들어 `keyword=공연`은 서울시 원본 분류가 `콘서트`인 행사도 찾는다. 입력한 `%`, `_` 등은 검색 패턴이 아닌 일반 문자로 취급한다. 한 검색어를 공백으로 분리해 여러 조건으로 만들지는 않는다.

| `sort` 값 | 화면 표시 | 정렬 순서 |
|---|---|---|
| `startDateAsc` | 시작 시간순 | 행사 시작일 오름차순, 같은 시작일이면 행사 ID 오름차순 |
| `endDateAsc` | 종료 임박순 | 종료되지 않은 행사를 종료일이 가까운 순으로 먼저 배치한다. 종료된 행사는 뒤에 두고 최근 종료일부터 보여준다. 같은 종료일이면 행사 ID 오름차순 |
| `titleAsc` | 행사명순 | 행사명 오름차순, 같은 행사명이면 행사 ID 오름차순 |

화면의 `시작 시간순`은 DB의 `event_start_time`이 아닌 행사 **시작 날짜** 기준이다. `종료 임박순`도 지난 행사를 결과에서 제외하지는 않는다. 검색 조건에 맞는 전체 목록을 정렬한 다음 페이지 크기를 적용한다.

## 응답과 오류

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "eventId": "12345",
        "title": "행사명",
        "category": "전시",
        "district": "종로구",
        "startDate": "2026-09-01",
        "endDate": "2026-09-30",
        "freeYn": null,
        "fee": null,
        "imageUrl": null
      }
    ],
    "page": 0,
    "totalCount": 1
  },
  "message": null
}
```

`totalCount`는 페이지 크기를 적용하기 전, 모든 검색 조건에 맞는 전체 행사 수다. 결과가 0건이면 200과 `items=[]`, `totalCount=0`을 반환한다. 유효하지 않은 월·분야·정렬·페이지 값, 빈 키워드, `true`·`false` 이외의 `freeYn`은 400, 인증 정보가 없으면 401을 반환한다. 요금 정보가 없으면 `freeYn`과 `fee`는 `null`일 수 있으며 화면에는 `요금 정보 없음`으로 표시한다.
