# components — 재사용 UI 조각

여러 화면에서 **반복해서 쓰이는 UI 부품**을 둡니다.

## 예시

| 컴포넌트 | 쓰이는 곳 |
|---|---|
| `EventCard` | 메인 화면 검색 결과, 마이페이지 |
| `PlanItemCard` | 일정 목록의 장소 카드 |
| `Header` | 모든 화면 상단 (로고·즐겨찾기·마이페이지) |
| `Modal` | 행사 상세, 확인 창 |
| `Button`, `Input` | 전역 |

## 파일명 규칙

```
{컴포넌트명}.jsx    ← 첫 글자 대문자 (PascalCase)
```

## 좋은 컴포넌트란

- **한 가지 일만** 합니다 (카드는 카드만 그림)
- 데이터는 **props로 받습니다** (내부에서 직접 API를 부르지 않음)
- 이름만 봐도 무엇인지 알 수 있습니다

```jsx
// ✅ 좋은 예 — 받은 데이터를 그리기만 함
<EventCard title="고궁의 밤" date="2026-09-20" onClick={handleClick} />
```
