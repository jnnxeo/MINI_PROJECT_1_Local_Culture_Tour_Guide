# contexts — 전역 상태

여러 화면이 **함께 써야 하는 값**을 보관합니다.

## 왜 필요한가요?

로그인 정보는 헤더·마이페이지·일정 저장 등 여러 곳에서 필요합니다.
props로 계속 넘기면 복잡해지므로, Context에 담아 **어디서든 꺼내 쓰게** 합니다.

## 예시

| 파일 | 담는 것 |
|---|---|
| `AuthContext.jsx` | 로그인 여부, 사용자 정보, 토큰 |
| `PlanContext.jsx` | 작성 중인 일정 (선택) |

## 주의

⚠️ **모든 상태를 Context에 넣지 마세요.** 한 화면에서만 쓰는 값은 `useState`로 충분합니다.
Context에 넣으면 값이 바뀔 때 관련된 화면이 전부 다시 그려집니다.
