# pages — 화면 단위 컴포넌트

**URL 하나에 대응되는 화면 전체**를 그리는 컴포넌트입니다.

## 만들어야 할 화면

| 파일 | URL | 화면ID | 설명 |
|---|---|---|---|
| `LoginPage` | `/login` | SCR-001 | 이메일·비밀번호 로그인 |
| `SignUpPage` | `/signup` | SCR-002 | 회원가입 |
| `MainPage` | `/` | SCR-003 | 조건 입력 + AI 추천 결과 + 지도 |
| `MyPage` | `/mypage` | SCR-004 | 저장한 일정·즐겨찾기 |

## 파일명 규칙

```
{화면명}Page.jsx   (또는 .tsx)
```

> 💡 페이지가 너무 길어지면 **일부를 `components/`로 빼세요.**
> 한 파일이 300줄을 넘어가면 나눌 때가 된 신호입니다.
