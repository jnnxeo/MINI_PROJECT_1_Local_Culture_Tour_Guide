# styles — 공통 CSS

여러 화면에서 함께 쓰는 스타일을 둡니다.

| 파일 예시 | 역할 |
|---|---|
| `globals.css` | 전체 기본 스타일 (폰트·여백 초기화) |
| `variables.css` | 색상·간격 값 정의 |

## 색상 값을 변수로 두면 좋습니다

Figma 시안의 색상을 한곳에 정의해두면 **나중에 한 번에 바꿀 수 있습니다.**

```css
:root {
  --color-primary: #2563eb;   /* 포인트 파랑 */
  --color-navy:    #111c3d;   /* 헤더 남색 */
  --color-border:  #e2e8f0;   /* 테두리 회색 */
  --color-text:    #1e293b;   /* 본문 글자 */
}
```

> 특정 컴포넌트에만 쓰는 스타일은 그 컴포넌트 옆에 두는 편이 낫습니다.
